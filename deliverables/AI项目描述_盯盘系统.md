## 详细版（约 520 字，推荐）

我用 AI 从零做了一套「A 股盯盘系统」——一个跑在自己电脑上、手机连同一 WiFi 也能看的本地实时看板，专门服务于我自己的场外基金持仓（4 只，覆盖人工智能、CPO、半导体、创新药等主题）。

系统是纯 Python 3 写的本地 HTTP 服务（19 个模块、约 7600 行）加一个约 2000 行的单页看板（原生 JS + 手绘 SVG，不依赖任何图表库）。功能包括：东财/新浪实时行情、板块轮动与资金流向、市场状态机（趋势/震荡/强弱）、跨资产风险开关（国债 + 黄金）、题材情绪归拢，以及最核心的「**基金级趋势预测**」——用每只基金自己的净值序列，算出未来 5 日的期望涨跌幅、1σ 区间和上行概率。此外还有每天 14:50 自动生成的调仓建议、夜间净值结算、服务看门狗自愈。

开发中靠 AI 解决了不少真问题：
1. **数据源迁移**：从商业接口 iFinD 整体迁到东财 + 新浪免费接口，把数据成本降到零。
2. **金额口径 bug**：官方净值公布早于夜间结算，中间窗口会「重复计息」导致当日收益凭空消失——最后改成由结算日判断而非来源标记，并加后台线程即时结算。
3. **反复出现的「改了代码不生效」**：根因是 Windows 下多个服务实例同时抢占同一端口，旧实例接走了请求，靠数进程定位。
4. **质量保障**：写了 4 套自动化回归测试（约 170 项断言），每次改动必跑；还接真实浏览器（Edge）做端到端验证。

整个开发基本是「自然语言描述需求 → AI 写代码/调试/自检 → 真机验证」的循环：我负责判断方向与验收，AI 负责实现与排错。
